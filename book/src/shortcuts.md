# Keyboard shortcuts

| Keys | Action |
|---|---|
| 0–9 | Fret number |
| ← → ↑ ↓ | Move between beats and strings |
| Shift+← / → | Extend the selection |
| Space | Play / stop |
| + / − | Longer / shorter note |
| Alt+1 … Alt+7 | Whole … 64th note |
| . | Dotted |
| / | Triplet |
| R, L, X, G | Rest, tie, dead note, ghost note |
| P, H, S, B, V, A, I | Palm mute, hammer-on, slide, bend, vibrato, accent, let ring |
| Backspace / Delete | Delete note |
| ⌘Z / ⇧⌘Z | Undo / redo |
| ⌘C / ⌘X / ⌘V | Copy / cut / paste |
| ⌘A, Esc | Select all, deselect |
| ⌘↑ / ⌘↓ | Transpose a semitone |
| ⌘N / ⌘O / ⌘S / ⇧⌘S | New / open / save / save as |
| ⌘+ / ⌘− / ⌘0 | Zoom |
