# UI parity

> **Last reviewed:** 2026-10-15 · **Last updated:** 2026-10-15 · **Change:** major (first list) · **Target:** Guitar Pro 8

Guitar Pro 8's workspace, element by element. Part of [target-app parity](target-app-parity.md);
gap G8 in [gaps](gaps.md). Menu wiring is measured separately in
[parity-checklist.md](parity-checklist.md).

| Element | Guitar Pro 8 | Guitario | Status |
|---|---|---|---|
| Top bar | document buttons, transport, LCD, speed, view toggles | same layout; LCD shows track, bar, beat, signature, time and tempo | done |
| Document tabs | several open documents | one document, one tab | partial |
| Edition palette | note values, rhythm, dynamics, articulations, effects, bar tools | the same groups, live state; no tapping, slap/pop, fingering, grace notes | partial |
| Score view | page, screen, horizontal layouts; multitrack | page layout, one track at a time | partial |
| Engraving | standard, tab, slash, drums, chord diagrams, lyrics | standard and tab (see [scorecard](scorecard.md#notation-and-engraving)) | partial |
| Inspector | Song, Track, Bar, Note/Beat | Song and Track | partial |
| Global view | track list with mixer controls and bar grid | track rows with mute/solo/volume, bar grid with markers, selection and playback | done |
| Instrument views | fretboard, keyboard, drum pad | fretboard (click to enter notes) and drum pad (click to toggle hits) | partial |
| Mixer | per-track volume, pan, effects; master | volume/pan/mute/solo in inspector and global view | partial |
| Tools | tuner, chord engine, scales, line in | none | missing |
| Preferences | dialog | persisted view and transport settings, no dialog | partial |
| Themes | light and dark | dark | partial |
| Keyboard | Guitar Pro shortcuts | digits, arrows, + − . / R L X G A I P H V S B, ⌘ shortcuts | partial |
| Unsaved changes | prompt on close, New and Open | prompt (craft-quit on macOS) | done |
| Languages | about a dozen | English | missing |
