Guitario is an open-source tablature and notation editor with Guitar Pro's layout, menus and shortcuts. It puts tab and standard notation on real pages, gives you playback you can loop and slow down, and opens and saves Guitar Pro files. It is native, offline and free.

If you know Guitar Pro, you already know Guitario

The same layout, menu bar and keys.

Click a beat, type a fret number, press P for palm mute or H for a hammer-on, then press Space to play. Every screenshot here is the real app, rendered offscreen from one of the demo scores.

01

Notation that reads like Guitar Pro

Standard notation and tab, joined by a bracket. You get time and key signatures, beamed rhythms, rests, tuplets, section boxes, tempo marks and repeats. The tab shows P.M. and let-ring lanes, vibrato, slides and hammer-on arcs.

  • Any tuning from 4 to 12 strings
  • Presets for drop D, D and C standard, drop B and seven-string
  • Odd meters such as 7/8, 13/16 and 12/8, with tempo and key changes

02

Hear it, loop it, slow it down

A plucked-string model plays palm mutes, dead notes, bends, vibrato and legato slides. Sampled drums, bass and guitar come from an SFZ bank and play through an amp.

  • Loop a selection and slow it to 25% without changing pitch
  • Metronome, count-in, and the sounding note shown on the fretboard
  • Export WAV, FLAC or MIDI

03

Bends you draw

There are seven bend kinds, from a quick quarter-tone to a prebend and release, and each is drawn on the page the way Guitar Pro draws it. Open the Bend window to drag the curve's points, double-click to add one, and listen to the result. Whammy-bar dives and dips are written in the score too.

04

Drums, with a pad

Drum-kit tracks get a percussion staff, a drum pad and a step grid. Guitar Pro's two-digit entry works too: 3 then 6 is a kick.

  • A second voice for the feet
  • General MIDI drums with hi-hat choke
  • Drum tab export

05

Pages that print

File › Print Preview shows exactly what the PDF will contain: vector pages with embedded font subsets and selectable text, one section per track. Choose A4, A5, Letter or Legal, portrait or landscape, and set your own margins. Print from the app, or export from the command line.

Editing

Fret entry from the keyboard or the fretboard and Guitar Pro's single-key techniques. Select, copy, cut, paste and transpose. Voices 1 to 4, grace notes, trills, tremolo picking, chord diagrams and lyrics. Every edit can be undone.

Files

Opens .gp3, .gp4, .gp5, .gpx and .gp, MIDI and MusicXML. Saves .gt atomically. Exports .gp, .gp5, PDF, MIDI, WAV, FLAC and ASCII tab.

Practice

A tuner, chord and scale tools, a fretboard that follows the music, and looped playback at any speed. Built for learning a riff, not just writing one.

Fast and native

egui on wgpu, with no webview. Audio runs on its own thread, so the UI never blocks it. Layout, playback and file reading are timed against a budget on a 400-bar score.

Built for agents

Every edit is a command.

Each action, from setting a fret to exporting a PDF, is an engine command with a stable id and JSON params. The UI, the CLI and the tests all go through it, so anything you can click, a script or an AI agent can do too, and each edit is one undo step.

  • guitario-cli commands lists every command with its params
  • convert goes between .gt, .gp, .gp5, PDF, MIDI, WAV, FLAC and text
  • A fuzz test sends hostile params to every registered command

A live control channel and an MCP server are on the roadmap.

riff.json

[
  ["score.setMeta",    {"title": "Chug Study"}],
  ["measure.setTempo", {"bpm": 190}],
  ["cursor.set",       {"measure": 0, "beat": 0, "string": 5}],
  ["note.setFret",     {"fret": 0}],
  ["note.toggleEffect", {"effect": "palmMute"}]
]

terminal

# run the script and save the result
$ guitario-cli run - riff.json --save riff.gt

# any format to any format
$ guitario-cli convert song.gp song.pdf
$ guitario-cli convert riff.gt riff.wav

How it's built

Pure Rust, from bottom to top.

There is no JavaScript, Tauri, Electron or webview anywhere. The desktop app is native egui on wgpu, and everything below the UI also builds for WebAssembly.

Layered crates
A crate may depend only on lower layers, and cargo xtask layers enforces it on every change.
Never crash
Shipped code has no unwrap, panic or unsafe, every reader checks hostile input, and a failing command rolls back exactly.
Clean-room
Only behaviour and look are matched, from public format notes and observation. Nothing is copied from other tab software.
  1. L6ui-eguithe shell in Guitar Pro's layout
  2. L5enginesession and command registry
  3. L4audiosound-card output
  4. L3format · gp · musicxml.gt, Guitar Pro 3–8, MusicXML
  5. L2midi · playbacktempo map, synth, WAV
  6. L1scorethe document model
  7. L0theorydurations, tunings, pitch

Get started

Build it, open a demo, play.

You need a recent stable Rust toolchain. Then click a beat, type a fret number and press Space.

cargo xtask package builds a package for your platform into dist/: an app bundle and disk image on macOS, a .deb and a tarball on Linux, and an installer on Windows. Releases are not signed yet.
